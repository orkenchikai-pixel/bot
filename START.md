# Запуск бота на сервере: пошаговая инструкция

Инструкция для тех, кто никогда не работал с серверами. Программировать не нужно: вы скопируете одну команду и ответите на вопросы мастера установки — остальное он сделает сам.

**Сколько времени:** около часа. Подтверждение компании в Meta иногда занимает несколько дней, но бота можно установить и проверить в браузере, не дожидаясь его.

## Что понадобится

| Что | Где взять |
|---|---|
| Сервер (VPS): Ubuntu 24.04, 2 ГБ памяти, от 20 ГБ диска | хостинг с дата-центром в стране клиники |
| Домен или поддомен (например, `bot.my-clinic.kz`) | регистратор доменов или DNS сайта клиники |
| Ключ Claude API | [platform.claude.com](https://platform.claude.com) |
| Номер WhatsApp и кабинет Meta — можно позже | [business.facebook.com](https://business.facebook.com), [developers.facebook.com](https://developers.facebook.com) |
| Telegram для уведомлений администратору — по желанию | любой аккаунт |

**Где должен стоять сервер.** Казахстан: персональные данные граждан РК нужно хранить на серверах в Казахстане — выбирайте хостинг с дата-центром в РК. Россия: по 152-ФЗ данные граждан РФ собираются и хранятся в базах на территории России. Подробнее — в [COMPLIANCE.md](COMPLIANCE.md).

## Шаг 1. Арендуйте сервер

1. На сайте хостинга выберите VPS (виртуальный сервер): 2 ГБ памяти, 1–2 процессора, от 20 ГБ диска. Сервер с 1 ГБ тоже подойдёт — мастер сам добавит файл подкачки.
2. Операционная система — **Ubuntu 24.04** (подойдут Ubuntu 22.04 и Debian 12).
3. После оплаты хостинг пришлёт **IP-адрес** сервера (вида `185.22.33.44`) и **пароль пользователя root**. Сохраните их.

## Шаг 2. Направьте домен на сервер

В настройках DNS у регистратора домена добавьте запись:

| Тип | Имя | Значение |
|---|---|---|
| A | `bot` | IP-адрес вашего сервера |

Получится адрес `bot.ваш-домен.kz`. Запись начинает работать через 5–30 минут, иногда дольше. Если у этого имени есть запись **AAAA** — удалите её.

## Шаг 3. Подключитесь к серверу

**Windows 10/11:** нажмите «Пуск», наберите `PowerShell` и откройте его. **Mac:** Launchpad → «Терминал».

Введите эту команду (вместо цифр — IP вашего сервера) и нажмите Enter:

```bash
ssh root@185.22.33.44
```

- На вопрос `Are you sure you want to continue connecting` напишите `yes` и нажмите Enter.
- Введите пароль root и нажмите Enter. **Символы пароля при вводе не отображаются** — это нормально.
- Вы на сервере, если строка начинается с `root@`.

Как вставить скопированный текст: в PowerShell — правая кнопка мыши (или Ctrl+V), в «Терминале» Mac — Cmd+V.

> Можно работать и через «Консоль» (VNC) в панели хостинга, но в ней часто не работает вставка текста и русские буквы. Если столкнулись с этим — подключитесь через PowerShell или «Терминал».

## Шаг 4. Запустите мастер установки

### 4.1. Создайте токен GitHub

Код бота лежит в закрытом репозитории, поэтому серверу нужен «пропуск» — токен с правом только на чтение:

1. Войдите на [github.com](https://github.com) в аккаунт, где лежит репозиторий, нажмите на фото профиля справа вверху → **Settings**.
2. Слева внизу: **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
3. **Token name** — например, `dental-bot`. **Expiration** — максимальный срок.
4. **Repository access** → **Only select repositories** → выберите `orkenchikai-pixel/bot`.
5. **Permissions** → **Repository permissions** → **Contents** → **Read-only**.
6. Нажмите **Generate token** и скопируйте токен (начинается с `github_pat_`). GitHub покажет его только один раз.

Один токен подойдёт для всех ваших серверов. Если токен попал в чужие руки, удалите его там же (Delete) и создайте новый.

### 4.2. Вставьте команду установки

Скопируйте команду целиком, вставьте в окно сервера и нажмите Enter:

```bash
read -rsp "Токен GitHub: " GITHUB_TOKEN && echo && export GITHUB_TOKEN && bash <(curl -fsSL -H "Authorization: Bearer $GITHUB_TOKEN" -H "Accept: application/vnd.github.raw" https://api.github.com/repos/orkenchikai-pixel/bot/contents/install.sh)
```

Команда попросит токен: вставьте его и нажмите Enter (символы при вводе не отображаются). Установщик сохранит токен на сервере, чтобы потом скачивать обновления.

Мастер задаст вопросы. Ответ вводите и подтверждайте клавишей Enter. В квадратных скобках — ответ по умолчанию: его можно принять, просто нажав Enter.

| Вопрос | Что ответить |
|---|---|
| Домен | `bot.ваш-домен.kz` из шага 2 |
| Ключ Claude | [platform.claude.com](https://platform.claude.com) → API Keys → Create Key. Там же в Billing пополните баланс и поставьте месячный лимит расходов |
| Название, адрес, телефон, часы работы | так, как их увидят пациенты |
| Юрлицо | ТОО или ИП клиники — оно попадёт в запрос согласия на обработку данных |
| Политика конфиденциальности | ссылка на страницу сайта клиники; если её пока нет — Enter |
| Подключить WhatsApp сейчас? | «2 — Позже», если данных из Meta ещё нет (их добавите в шаге 7) |
| Уведомления в Telegram | «д» и следуйте подсказкам (подробнее — шаг 8) |

Ключи мастер проверяет сразу: неверный ключ, пустой баланс Claude, временный токен WhatsApp или App Secret от другого приложения он заметит и попросит ввести заново.

Дальше мастер сам установит Docker, сгенерирует пароли и ключ шифрования базы, соберёт и запустит бота и получит HTTPS-сертификат — это 5–10 минут. В конце он покажет:

- ссылку на **тестовый чат**;
- **ключ шифрования базы** и **токен администратора** — сохраните их в менеджере паролей;
- что вписать в настройки Meta.

Если что-то пошло не так, запустите ту же команду ещё раз: это безопасно, ответы и ключи сохраняются.

## Шаг 5. Проверьте бота в браузере

Откройте ссылку `https://bot.ваш-домен.kz/simulator#key=…` из итогового экрана (показать её снова: `dental-bot info`). Напишите как пациент: «Сколько стоит чистка?», «Запишите меня к терапевту на завтра». Справа видны записи и уведомления, которые получил бы администратор. Симулятор пишет в отдельную базу и не занимает время врачей.

Ссылку можно дать сотрудникам клиники — доступа к данным пациентов она не даёт.

## Шаг 6. Впишите свой прайс и врачей

Сейчас в боте **демо-прайс и вымышленные врачи**. Замените их до подключения WhatsApp:

```bash
dental-bot edit
```

Откроется редактор nano с файлом клиники. Меняйте значения в кавычках и цифры; запятые, двоеточия и скобки не трогайте.

Услуга:

```json
{ "id": "caries", "category": "Лечение зубов", "name": "Лечение кариеса с пломбой", "price_from": 18000, "price_to": 35000, "duration_min": 60 }
```

- `id` — латиницей, без пробелов: по нему врачи «знают» свои услуги;
- `price_from` и `price_to` — цена «от» и «до», `"price_fixed": true` — точная цена без «от»;
- `duration_min` — сколько минут занимает приём;
- `"bookable": false` — на услугу нельзя записаться напрямую (например, имплантация: сначала консультация).

Врач:

```json
{
  "id": "aliyeva",
  "name": "Алиева Динара Маратовна",
  "specialty": "стоматолог-терапевт",
  "services": ["consult", "caries"],
  "schedule": { "mon": [["09:00", "13:00"], ["14:00", "18:00"]], "tue": [["09:00", "18:00"]] },
  "days_off": ["2026-12-28", "2026-12-29"]
}
```

- `services` — `id` услуг, которые выполняет врач;
- `schedule` — часы работы по дням: `mon tue wed thu fri sat sun`; два интервала в день — перерыв между ними;
- `days_off` — отпуск и больничные; `holidays` в начале файла — дни, когда закрыта вся клиника.

Заполните и тексты: `about` (о клинике), `payment_methods` (способы оплаты), `faq` (частые вопросы), `policies` (правила), `promotions` (акции). Бот отвечает пациентам только по этим данным и ничего не выдумывает.

Сохранить — **Ctrl+O**, затем Enter; выйти — **Ctrl+X**. После выхода файл проверяется: если где-то ошибка (например, пропущена запятая), бот предложит исправить её или вернёт прежнюю версию — сломать работающего бота правкой нельзя.

> Совет: пришлите Claude прайс клиники (Excel, PDF или фото) и попросите: «Сделай массив services в формате clinics/demo.json».

## Шаг 7. Подключите WhatsApp

### 7.1. Кабинет Meta

1. [business.facebook.com](https://business.facebook.com) — создайте бизнес-портфолио клиники или войдите в существующее.
2. [developers.facebook.com](https://developers.facebook.com) → My Apps (Мои приложения) → Create App → тип **Business** → добавьте продукт **WhatsApp**.
3. WhatsApp → **API Setup**. Сначала Meta выдаёт тестовый номер. Для настоящего номера клиники нажмите **Add phone number** и подтвердите номер кодом из SMS. Номер не должен быть занят обычным приложением WhatsApp.
4. Там же скопируйте **Phone number ID** — длинное число рядом с номером (это не сам номер телефона).

### 7.2. Постоянный токен

Токен на странице API Setup временный — он перестаёт работать через сутки. Постоянный:

1. [business.facebook.com](https://business.facebook.com) → **Настройки компании** → Пользователи → **Системные пользователи** → Добавить, роль «Администратор».
2. **Назначить активы**: ваше приложение и аккаунт WhatsApp, полный доступ.
3. **Сгенерировать новый токен**: выберите приложение, срок действия «Никогда», разрешения `whatsapp_business_messaging` и `whatsapp_business_management`. Скопируйте токен — он начинается с `EAA`.

### 7.3. App Secret

[developers.facebook.com](https://developers.facebook.com) → ваше приложение → **Настройки приложения → Основное** → Секрет приложения → Показать.

### 7.4. Подключение на сервере

```bash
dental-bot whatsapp
```

Команда проверит номер, токен и App Secret через Meta и покажет данные для вебхука.

### 7.5. Вебхук

[developers.facebook.com](https://developers.facebook.com) → ваше приложение → WhatsApp → **Configuration** → Webhook → Edit:

- **Callback URL** — `https://bot.ваш-домен.kz/webhook/whatsapp`
- **Verify token** — из вывода команды (показать снова: `dental-bot info`)

Нажмите **Verify and save**, затем в списке **Webhook fields** у поля `messages` нажмите **Subscribe**.

### 7.6. Проверка

Напишите на номер клиники со своего телефона. Бот попросит согласие на обработку данных (кнопки «Согласен» / «Не согласен») и ответит.

- С тестовым номером Meta бот отвечает только номерам из списка получателей: API Setup → To → Manage phone number list.
- Чтобы писать пациентам с настоящего номера, Meta попросит подтвердить компанию (Business verification) и одобрить отображаемое имя.

## Шаг 8. Уведомления администратору в Telegram

```bash
dental-bot telegram
```

В Telegram создайте бота у @BotFather (команда `/newbot`), вставьте его токен, затем нажмите «Запустить» у своего бота — мастер сам найдёт чат и пришлёт тестовое сообщение. Чтобы уведомления получали все администраторы, добавьте бота в общую группу и напишите там любое сообщение.

## Команды на каждый день

| Команда | Что делает |
|---|---|
| `dental-bot status` | всё ли работает: бот, HTTPS, настройки, резервные копии |
| `dental-bot logs` | журнал в реальном времени (выход — Ctrl+C) |
| `dental-bot edit` | изменить прайс, врачей, расписание, отпуска |
| `dental-bot info` | ссылки, тестовый чат, данные для Meta |
| `dental-bot update` | обновить бота: сначала резервная копия, а если новая версия не запустится — возврат к прежней |
| `dental-bot backup` | резервная копия базы прямо сейчас |
| `dental-bot add-clinic` | подключить ещё одну клинику к этому же серверу |
| `dental-bot help` | все команды |

Если вы вошли не как root, добавляйте `sudo`: `sudo dental-bot status`.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| Мастер пишет «HTTPS пока не работает» | Проверьте A-запись домена (шаг 2) и что в панели хостинга открыты порты 80 и 443. Подождите и выполните `dental-bot status` |
| Meta: «The callback URL or verify token couldn't be validated» | Откройте в браузере `https://bot.ваш-домен.kz/health` — должно быть `{"ok":true}`. Скопируйте Verify token заново из `dental-bot info` |
| Бот не отвечает в WhatsApp | Выполните `dental-bot logs` и напишите боту — в журнале будет видно, что происходит. Проверьте подписку на поле `messages` (7.5), список получателей у тестового номера и что токен постоянный |
| В журнале «credit balance is too low» | Пополните баланс в platform.claude.com → Billing |
| Команда установки выдаёт ошибку 404 | Токен GitHub введён неверно, не имеет доступа к репозиторию или истёк. Создайте новый (шаг 4.1) |
| `dental-bot update` пишет «Не удалось скачать обновление» | Скорее всего, истёк токен GitHub. Создайте новый (шаг 4.1) и выполните команду установки ещё раз — она обновит бота и сохранит новый токен |
| Потерялась ссылка на тестовый чат | `dental-bot info` |
| Нужно перенести бота на другой сервер | Установите бота мастером на новом сервере и остановите на обоих (`dental-bot stop`). Перенесите из `/opt/dental-bot` файл `.env` и папки `clinics.local` и `data`, затем на новом сервере выполните `dental-bot start` |

Подробный журнал установки и команд — `/var/log/dental-bot.log`.

## Безопасность — коротко

- Ключ шифрования базы и токен администратора храните в менеджере паролей. Без ключа данные из резервных копий не восстановить.
- Не пересылайте файл `.env` и ключи в мессенджерах.
- Раз в неделю выполняйте `dental-bot update`. Резервные копии лежат в `/opt/dental-bot/data/backups` — регулярно скачивайте их к себе (WinSCP или FileZilla, протокол SFTP).
- Полный чек-лист — [SECURITY.md](SECURITY.md); персональные данные и закон — [COMPLIANCE.md](COMPLIANCE.md).
